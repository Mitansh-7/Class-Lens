# ClassLens — Two-minute demo script

## Opening (0:00–0:20)

“Good morning. ClassLens is a classroom assessment tool designed for Computer Science teachers. A normal quiz tells us the score; ClassLens helps us understand which concepts need to be taught again and what to do next.”

## Create an assessment (0:20–0:45)

“From **Create Quiz**, I can make an assessment for my class without writing any code. I enter the quiz details, add multiple-choice questions, mark the correct answer, explain it, and tag each question with a topic such as loops or arrays. I can preview it, save a draft, or publish it.”

*Demo action:* Open **Create Quiz** and show the question editor. If time is short, use the sample quiz for the rest of the demo.

## Take the quiz (0:45–1:05)

“Students can answer the published quiz on the classroom device. The quiz supports question navigation and a review before submission. After submission, ClassLens calculates the score from the saved answer key and explains each answer.”

*Demo action:* Open **My Quizzes**, choose a published quiz, start it, answer a few questions, and submit.

## Turn answers into teaching action (1:05–1:40)

“The important part is what happens next. ClassLens groups responses by topic, shows accuracy and frequently chosen wrong answers, and flags likely misconceptions using transparent rules. It does not claim to use AI. The teacher can see the evidence behind each flagged topic.”

*Demo action:* Open **Learning Gaps**, point out a topic with lower accuracy and the evidence shown for it.

“Then the **Revision Planner** turns those gaps into classroom actions—for example, using a trace table to reteach loops and giving students a short follow-up assessment. A teacher can track the intervention and review later attempts.”

*Demo action:* Open **Revision Planner** and show one recommendation.

## Close (1:40–2:00)

“ClassLens connects assessment to instruction: create a quiz, assess understanding, identify learning gaps, plan targeted revision, and assess again. It is a working browser-based prototype that stores data locally, so it does not require paid services or send student responses to a server. It currently supports multiple-choice questions, and future versions could add Punjabi and Hindi interfaces, more question types, and secure multi-device sharing.”

## Demo checklist

- [ ] Open the dashboard and explain that sample records are fictional and labelled.
- [ ] Show the quiz builder and its topic tags.
- [ ] Complete at least one quiz attempt.
- [ ] Show the new attempt in the results and learning-gap analysis.
- [ ] Show one matching revision recommendation.
- [ ] If asked, explain that analysis is rule-based, not AI.
- [ ] If asked, explain that localStorage keeps data in this browser only.
- [ ] Do not claim classroom-proven impact or multi-device synchronisation.
